## 步骤 1：用 AI 编程工具生成 daily_digest.py

**提示词：**

```plain
请帮我编写 ~/ai-knowledge-base/v4-production/daily_digest.py 每日推送入口脚本：

需求：
1. 从 formatter.py 加载文章
2. 过滤 relevance_score < 60 的低质量文章
3. 调用 publisher.py 的 publish_daily_digest() 推送到所有渠道
4. 打印推送结果汇总（成功/失败渠道数）
5. 没有高质量文章时跳过推送并打印警告

编码规范：PEP 8，包含 if __name__ == "__main__" 入口
```
**生成的代码：**（参考实现）
```plain
"""daily_digest.py — 每日推送入口。"""

import asyncio
import logging
from distribution.publisher import publish_daily_digest


async def main():
    logging.basicConfig(level=logging.INFO, format="%(asctime)s [%(levelname)s] %(message)s")

    print("=" * 50)
    print("  AI 知识库 — 每日摘要推送")
    print("=" * 50)

    # 调用统一发布入口：生成简报 + 并发推送到所有渠道
    results = await publish_daily_digest()

    # 汇总
    success = sum(1 for r in results if r.success)
    print(f"\n推送结果: {success}/{len(results)} 个渠道成功")
    for r in results:
        status = "✅" if r.success else "❌"
        print(f"  {status} {r.channel}: {r.message_id or r.error}")


if __name__ == "__main__":
    asyncio.run(main())
```

```plain
# 每日简报技能

## 触发条件

当用户想要查看今日 / 本周 AI 技术汇总时激活。
典型触发词：简报、摘要、今日、daily、digest、briefing

## 生成流程

> **重要 · 只允许 Read**：本技能不能用 Glob / Grep / exec。所有操作从 `Read knowledge/articles/index.json` 开始。

### Step 1: 读索引定位今日数据

用 `Read` 读 `knowledge/articles/index.json`（含每篇文章的 `id` / `title` / `category` / `relevance_score` / `tags` / `collected_at`）。

**在内存里筛**今日的条目（`collected_at` 字段以今日日期开头）；今日无数据则回退到最近 7 天。

> **不要尝试 Glob 或 grep 文件名** —— 索引文件已经聚合了所有元信息，一次 Read 就够了。

### Step 2: 内存过滤 + 排序

1. 过滤 `relevance_score >= 0.6` 的条目
2. 按 `relevance_score` 降序排序
3. 取 Top 5

只对最终要进简报的 Top 5，用 `Read knowledge/articles/{id}.json` 拿 `summary` / `url` 等完整字段（**不要批量读全部**）。

### Step 3: 按 category 分组生成 Markdown 简报

## 与 Publisher 的分工

- **本 Skill**：格式化文本，生成 Markdown 简报
- **distribution/publisher.py**：把简报推送到 Telegram / 飞书 / 文件

Skill 负责"写"，Publisher 负责"发"。
```

## 步骤 4：配置 Cron 定时任务

**主线方案：系统 Crontab**

```plain
crontab -e
```
添加（注意用绝对路径 + python3 全路径）：
```plain
# 每天早上 8:00 推送
0 8 * * * cd /home/$USER/ai-knowledge-base/v4-production && /usr/bin/python3 daily_digest.py >> logs/cron.log 2>&1
```
确保日志目录存在：
```plain
mkdir -p ~/ai-knowledge-base/v4-production/logs
```
